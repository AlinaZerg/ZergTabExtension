# ZergTab

**ZergTab** — это расширение для браузера, которое заменяет стандартную страницу новой вкладки на настраиваемую канбан-доску для ваших ссылок.

## ✨ Возможности

- **Канбан-доска:** Организуйте ссылки в списки и перемещайте их перетаскиванием.
- **Рабочие пространства:** Создавайте отдельные пространства (например, «Работа», «Учёба», «Личное») с собственным фоном и цветом.
- **Гибкая настройка:** Меняйте тему, шрифт, акцентные цвета, отступы и ширину столбцов.
- **Сохранение сессий:** Сохраняйте все открытые вкладки в один клик в виде нового списка на доске.
- **Поиск:** Быстро находите нужные ссылки по названию или URL.
- **Импорт и экспорт:** Легко переносите свои данные или делайте резервные копии.
- **Импорт из Friendly Tab:** Переезжайте с этого расширения, сохраняя свои доски и ссылки.

## 🚀 Установка

На данный момент расширение не опубликовано в магазинах, но вы можете установить его вручную в режиме разработчика.

1.  Скачайте последний ZIP-архив со страницы [**Releases**](https://github.com/AlinaZerg/ZergTabExtension/releases).
2.  Распакуйте архив в любую удобную папку.
3.  Откройте браузер (Edge или Chrome) и перейдите на страницу `edge://extensions/` или `chrome://extensions/`.
4.  Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
5.  Нажмите **«Загрузить распакованное расширение»** и выберите папку, которую вы распаковали.
6.  Откройте новую вкладку — готово!
